# 🎵 Lo-Fi Experience

Uma página web imersiva com temática Synthwave/Lo-Fi desenvolvida para praticar a manipulação de mídias e estilização avançada com CSS.

## 🚀 Tecnologias Utilizadas
* **HTML5:** Estruturação de tags semânticas e elementos de `<audio>` e `<video>`.
* **CSS3:** Criação de gradientes lineares, efeito de vidro fumê (`backdrop-filter`) e animações contínuas (`@keyframes`) para simular luzes neon pulsantes.
* **JavaScript Vanilla:** Lógica para controle sintonizado das mídias (Play, Pause, Mute) e controle dinâmico de volume via slider (`input range`).
